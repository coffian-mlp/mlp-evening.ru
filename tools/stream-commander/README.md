# Stream Commander — демон управления стримом из чата

Локальный демон на машине стримера: слушает чат mlp-evening.ru и исполняет
команды владельца через obs-websocket. Работает в паре с ботом сайта (MLP-307):
демон **исполняет** команды в OBS, Лира **подтверждает** их репликой в чате.
Обе половины независимы — падение одной не ломает другую.

```
Владелец в чате: «Лира, включи перерыв»
        │
        ├────────► Centrifugo ► демон (этот скрипт) ► obs-websocket ► OBS
        │                                                    (сцена, пауза, серия)
        └────────► BotDispatch ► llm_jobs ► BotWorker ► LLM ► реплика Лиры в чат
```

## Команды (сообщение начинается с обращения к боту)

| Команда | Действие |
|---------|----------|
| Лира, включи начало | сцена `SCENE_START` |
| Лира, включи кино / фильм / серию | сцена кино; серия по счётчику; после паузы — с места |
| Лира, включи перерыв | пауза кино + сцена перерыва |
| Лира, следующая серия | счётчик +1, серия с начала |
| Лира, предыдущая серия | счётчик −1, серия с начала |
| Лира, включи ютуб | сцена `SCENE_YOUTUBE` |
| Лира, включи конец | сцена `SCENE_END` |

Обращение — «Лира» и её алиасы (плюс legacy-«Клод»); формулировка свободная:
ищется ключевое слово в тексте после обращения (регистр не важен, знаки
препинания допустимы). Матчер синхронизирован с `LLM\StreamCommand::isKnownCommand()`
— при добавлении команд обновлять оба.

## Автоматика (события OBS)

- **Конец серии** → сцена перерыва + счётчик серий +1.
- **Уход со сцены кино** (командой, мышкой, чем угодно) → автопауза плеера —
  иначе Media Source продолжает играть в фоне и зрители теряют кусок серии.

## Безопасность

- Исполняются только сообщения пользователя `OWNER_ID` (проверка по user_id,
  не по нику), созданные после старта демона.
- Пароль obs-websocket читается из конфига OBS на лету — в коде секретов нет.
- Чтение чата — гостевое (публичный Centrifugo-канал/SSE), демон в чат не пишет.

## Установка

```bash
python3 -m venv ~/.local/obs-claude-venv
~/.local/obs-claude-venv/bin/pip install requests obsws-python websocket-client
```

Требования в OBS (Сервис → Настройки сервера WebSocket → включить):

- Media Source с именем из `MOVIE_SOURCE` («Кино») в сцене `SCENE_MOVIE`
  (`restart_on_activate=false`, `close_when_inactive=false`);
- VLC Source с папкой роликов в сцене `SCENE_BREAK` (shuffle, `stop_restart`);
- сцены с именами из констант `SCENE_*`.

## Конфигурация

Константы в шапке `commander.py`: `OWNER_ID`, `SCENE_*`, `MOVIE_SOURCE`,
`EPISODES_DIR` (папка с сериями, сортировка по имени файла), `SITE_URL`.

Состояние: `~/.local/stream-commander/state.json` — `{"episode_idx": N}`
(0-based индекс серии в отсортированном списке). Переживает перезапуски;
редактировать можно руками при остановленном демоне.

Секреты: `~/.local/stream-commander/config.json` (права 600, **вне git**) —
`{"stream_token": "..."}`. Тот же токен лежит в `site_options.stream_command_token`
на сайте: по нему демон сообщает о автопереключениях (MLP-308), чтобы бот
прокомментировал их в чате. Нет файла или токена — события просто не отправляются.

Лог: `~/.local/stream-commander/commander.log`.

## Запуск

Штатно (macOS) — LaunchAgent: автостарт при загрузке + автоперезапуск при падении:

```bash
cp tools/stream-commander/ru.mlp-evening.stream-commander.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/ru.mlp-evening.stream-commander.plist
```

Остановка/перезапуск: `launchctl kickstart -k gui/$(id -u)/ru.mlp-evening.stream-commander`
(перезапуск) или `launchctl bootout gui/$(id -u)/ru.mlp-evening.stream-commander` (снять).
Пути в plist абсолютные — при другом расположении venv/скрипта поправить.

Разово без launchd:

```bash
nohup ~/.local/obs-claude-venv/bin/python3 tools/stream-commander/commander.py >/dev/null 2>&1 &
```

На Windows аналог — Планировщик задач (при переносе).

## Перенос на другую машину (в т.ч. Windows)

Код кроссплатформенный. При переносе поправить:

1. `OBS_WS_CONFIG` — путь к конфигу obs-websocket
   (macOS: `~/Library/Application Support/obs-studio/...`,
   Windows: `%APPDATA%\obs-studio\...`);
2. `EPISODES_DIR` и папку перерывов в OBS — под новые пути/буквы дисков;
3. пересоздать venv, скопировать `state.json`.

Сцены OBS переносятся экспортом коллекции сцен (пути внутри — поправить).

## Отладка

- Демон молчит на команду → `commander.log`: «Триггер без известной команды» =
  не совпал матчер; тишина = сообщение не дошло (проверить Centrifugo/SSE) или
  отфильтровано (чужой user_id, сообщение старше старта демона).
- OBS недоступен → команды падают с ошибкой в лог, демон живёт и ждёт.
- Centrifugo упал → автоматический фолбэк на SSE (задержка ответа 2–4 с вместо
  мгновенной), восстановление — само.
